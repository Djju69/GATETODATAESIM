# GATETODATA eSIM — Вопросы, требующие ответа владельца / поставщика

## Для TELMO (поддержка реселлера)

1. **Реальная спецификация API.** Публичный developer-портал помечен как placeholder. Пришлите, пожалуйста, финальную спецификацию (или доступ к API Explorer) для: списка пакетов, создания заказа, статуса заказа, баланса, webhooks.
2. **Промо-кампания.** Применяется ли моя кампания ($1, ≤100, min $5, первый заказ) к заказам, созданным через API? Есть ли параметр промокода в API? Если нет — кампания работает только в белом каталоге TELMO?
3. **Пополнение кошелька.** Доступные методы пополнения prepaid-кошелька и минимальная сумма.
4. **Webhooks.** Есть ли у моего аккаунта webhooks, как настроить URL и проверяется ли подпись (secret)? Список событий.
5. **Возвраты.** Возвращается ли списанная себестоимость в кошелёк при failed/refund-заказе?
6. **Ограничения реселлера.** Есть ли минимальная розничная цена / MAP-политика по пакетам?
7. **Сроки.** Активация срока действия пакета — с момента создания заказа или первого подключения?
8. **Тариф аккаунта.** Какой у нас уровень (Starter/Professional/Enterprise), включён ли API и sandbox?

## Для владельца (блокируют запуск продаж)

1. **TELMO_API_KEY** — ключ из личного кабинета (для probe и sync).
2. **TELEGRAM_BOT_TOKEN** и имя бота (указать в .env). Бот должен быть создан через @BotFather.
3. **USDT_WALLET_ADDRESS** — адрес TRON-кошелька для приёма оплат (TRC-20).
4. **ADMIN_TELEGRAM_ID** — ваш Telegram ID для уведомлений админу (узнать: @userinfobot).
5. **BASE_URL** — домен, на котором будет работать сайт (для deep links и писем).
6. **ADMIN_PASSWORD** — пароль админки (сильный).

## Для владельца (не блокируют, но влияют на план)

1. Юрлицо/ИП — планируются? (открывает карточный эквайринг: ЮKassa/CloudPayments и международные карты)
2. Домен и хостинг: есть ли уже VPS? Рекомендация: любой VPS 1 vCPU/1GB ($4–6/мес), Docker или PM2.
3. Нужны ли доп. языки интерфейса (сейчас RU; легко добавить EN — строки уже вынесены частично).
4. Брендинг: подтвердить нейминг «GATETODATA eSIM» и контакты поддержки (support@gatetodata.com — заглушка).
