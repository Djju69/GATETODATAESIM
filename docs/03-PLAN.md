## Осталось (следующие шаги)

1. **TELMO_API_KEY** → `npm run probe` → `npm run sync` — реальный каталог (демо затем `npm run seed-demo -- --off`).
2. **USDT_WALLET_ADDRESS** — включит крипто-оплату (Stars уже работает).
3. **Деплой на Vercel**: создать проект, добавить env (DATABASE_URL, TELEGRAM_*, BASE_URL), бот → webhook-режим (`/api/telegram`, заготовка в docs/06), Vercel Cron для USDT-страховки.
4. **SMTP-письмо** с ссылкой на eSIM (сейчас ссылка на странице и в боте).
5. **Telegram Login Widget** на сайте (связка сайта с ботом по telegram_id).
6. **Mini App** (/tg-app) и **реферальная система** (таблица есть) — v1.1.

## Команды

```bash
npm run dev          # сайт на http://localhost:3000
npm run bot          # Telegram-бот (long polling)
npm run probe        # проверка реальных endpoint'ов TELMO
npm run sync         # синхронизация каталога (реальные данные)
npm run watch:usdt   # наблюдатель USDT-платежей
npm run build        # прод-сборка
npm run seed-demo    # ДЕМО-наполнение для проверки UX (баннер на витрине, не для прода)
npm run backup       # бэкап SQLite + ротация 14 копий
node scripts/smoke-api.mjs [port]  # сквозной тест API (заказ → промокод → статус)
```

## Критерии готовности к запуску

- [ ] `npm run probe` показывает реальные данные TELMO
- [ ] `npm run sync` загрузил каталог (0 фиктивных цен)
- [ ] Тестовый заказ оплачен Stars → eSIM выдана автоматически
- [ ] Тестовый заказ оплачен USDT → watcher подтвердил и выдал
- [ ] Бот: покупка до конца без ошибок, включая повторный вход в «Мои eSIM»
- [ ] Админка: ретрай выдачи и повторная отправка работают
- [ ] .env заполнен, секреты не в репозитории
